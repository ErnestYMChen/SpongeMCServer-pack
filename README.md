# Sponge 整合包

一群朋友的 Minecraft 模組生存伺服器 **Sponge Server** 的整合包。

| 項目 | 版本 |
|---|---|
| Minecraft | 1.21.1 Java 版（限正版） |
| 模組載入器 | NeoForge（確切版本見 `pack.toml`） |

## 我是玩家，要怎麼安裝？

**不用從這裡下載任何東西。**

跟管理員拿 `Sponge-Player.zip`，照裡面的「安裝說明」做就好：安裝 Prism Launcher、匯入整合包、開始玩。
之後每次開遊戲，Prism 會自動從這裡抓最新的模組清單，模組有更新時你不需要做任何事。

伺服器位址也請跟管理員要。

## 這裡放的是什麼？

這裡只有整合包的「清單」，不是模組本身。模組檔案都是從 Modrinth 和 CurseForge 官方下載的。

| 檔案／資料夾 | 內容 |
|---|---|
| `pack.toml` | 整合包名稱、版本、Minecraft 和 NeoForge 版本 |
| `index.toml` | 所有檔案的清單 |
| `mods/` | 每個模組一個檔案，記錄下載位置和版本。**想知道有哪些模組就看這裡** |
| `config/` | 預設設定，例如已經調好、不會互相衝突的按鍵 |
| `world/datapacks/` | 伺服器規則 |

## 伺服器規則

- 死亡**不會**掉落物品（飾品欄也一樣）。
- 苦力怕爆炸**不會**破壞方塊，會變成煙火，但被炸到還是會受傷。
- 火**不會**蔓延。
- 難度：困難。PvP：開啟。
- 第一次進伺服器會自動拿到**新手包**：石製工具組、麵包、火把、床、原木，前 10 分鐘還有抗性和生命恢復。

## 遇到問題

開遊戲時卡住或下載失敗，大部分是網路問題，關掉 Prism 重開再試一次。
還是不行的話，把 Sponge 的 `minecraft\logs\latest.log` 傳給管理員。
